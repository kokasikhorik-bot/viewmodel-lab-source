## Обновление 0.64

Обновление для Windows, Android и iOS.

• Вместо полосок у счётчика патронов — текстурные патроны с наконечником, гильзой и основанием. Новые иконки профиля, чата, друзей, звука и остальных действий в карточке игрока.
• Консоль в стиле CS:GO: перемещаемое окно, моноширинный журнал, история, подсказки команд и аргументов, дополнение по Tab. `help` показывает поддерживаемые команды, `find` ищет их. Есть настройки FPS, чувствительности, звука, прицела и радара, настоящие бинды (`bind mouse4 +jump`), команды карт и офлайн-тренировки. Консоль доступна только офлайн; неподдерживаемые команды выдают ошибку.
• Радар с исходными обзорами карт CS:GO, цветными союзниками, направлением взгляда и полным квадратным обзором при TAB. Настраиваются центрирование, вращение, масштаб и размер отметок. Враги отмечаются по видимости; последняя известная позиция не следует за скрытым игроком и исчезает по таймеру.
• Новая заставка с оригинальным логотипом канала, именем Spiral и @SpiralEngine. Три анимации на выбор: проявление спирали, световой проход, сборка из дуг. Выбор: Настройки → Игра → Заставка Spiral. По умолчанию — первый вариант. Первый запуск Android показывает действительную подготовку ресурсов в той же заставке.
• Оптимизация: неподвижный прицел перестаёт пересобирать геометрию каждый кадр; отметки радара обновляются до 30 раз в секунду, направления окружностей и ссылки на ботов используются повторно. Убраны вложенные проверки союзников и строковые выделения при обновлении радара. Боты полигона готовятся при выборе полигона.

ПК: консоль открывается назначенной клавишей (~ / F1 по умолчанию), включая главное меню после выбора входа. На телефоне: Настройки → Игра → Консоль разработчика. Tab, стрелки и нажатие на строки работают в подсказках; `give` дополняет установленные оружия, `map` — карты. Это поддерживаемый набор совместимых команд, а не полный движок Source.

Windows: распакуйте весь ZIP и откройте SpiralEngine.exe. Android: подписанный APK 8.0+, ARM64, обновляется поверх старой версии. iOS: IPA 13.0+ без подписи для LiveContainer.

Проверены интерфейсы ПК/телефона, прежний HUD и сенсорное управление, границы видимости радара, подсказки, бинды, текстуры и три заставки. Нативный EXE проверен запуском через Wine / DirectX 11. Архивы проверены по содержимому, архитектуре и контрольным суммам. FPS на физической RTX 4060 или телефонах здесь не измерялся.

## Управление

Tab — таблица счёта; ПКМ по игроку — карточка. На телефоне нажмите строку игрока. B — выбор оружия; в дезматче он бесплатный. F2 — бонусное оружие. ~ / F1 — офлайн-консоль. Настройки → Управление — клавиши и мышь; Настройки → HUD — цвет интерфейса. В консоли: `help`, `find radar`, `cl_radar_scale 0.7`, `bind mouse4 +jump`.

## Онлайн

Используются существующие аккаунты, друзья, комнаты, официальный подбор и напарники. Результаты рейтинговых матчей фиксирует сервер. Старые ведущие комнат дезматча совместимы, но для новых очков и бонуса требуется ведущий 0.64. Отдельные ведущие работают на текущем стенде; круглосуточная работа не гарантируется.
