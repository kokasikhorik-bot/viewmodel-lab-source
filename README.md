## Обновление 0.63

Общее обновление для Windows, Android и iOS.

• Переработаны таблица счёта и карточка игрока: ПКМ на ПК, нажатие по строке на телефоне. Аватарки, статистика, доступные звания и действия с игроком.
• В дезматче — обычный круг выбора оружия с агентом и характеристиками, бесплатный выбор, очки, аватарки с тонкими рамками сторон и временное бонусное оружие с +50% очков.
• На ПК справа — силуэты имеющегося оружия с цифрами вместо полосок. Общий компактный счётчик патронов.
• Стандартный цвет HUD — нейтральный. Настройки → HUD: готовые цвета и свой RGB.
• Оптимизация: повторное использование моделей оружия ботов и HUD при возрождении; убрано синхронное чтение иконок с GPU и повторная отрисовка динамических теней в кубических отражениях. Частые вьюмоделы подготавливаются при загрузке карты.

В контрольном CPU-тесте 16 повторных смен оружия ботом: 91,15 → 0,18 мс, без новых моделей и наблюдаемого роста Mono-кучи после прогрева. Это отдельный тест, а не измерение FPS на RTX 4060.

Windows: распакуйте ZIP целиком и откройте SpiralEngine.exe. Android: APK 8.0+, ARM64, прежняя подпись для обновления поверх установленной игры. iOS: IPA 13.0+, без подписи для LiveContainer.

Проверены оба варианта интерфейса, сенсорное управление, сериализация сетевой статистики и все три нативные сборки. Windows EXE дополнительно запущен через Wine с DirectX 11. Физические телефоны и ПК для проверки FPS здесь недоступны.

Новости: https://t.me/SpiralEngine


## Управление

Tab — таблица счёта; ПКМ по игроку — карточка. На телефоне нажмите строку игрока. B — выбор оружия; в дезматче он бесплатный. F2 — взять активное бонусное оружие. Настройки → Управление — клавиши и мышь. Настройки → HUD — цвет интерфейса.

## Онлайн

Используются существующие аккаунты, друзья, комнаты, официальный подбор и напарники. Результаты рейтинговых матчей фиксирует сервер. Старые ведущие комнат дезматча совместимы, но для новых очков и бонуса требуется ведущий 0.63. Отдельные ведущие работают на текущем стенде; круглосуточная работа не гарантируется.
